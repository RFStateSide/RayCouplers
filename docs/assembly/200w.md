# 200 W population assembly

Use [common assembly instructions](common.md) and [the 200 W BOM](../../bom/200w/RayCoupler-200w-population.csv).

Variant checks: R1/R2/R4/R5 150 ohm; R3/R6 56 ohm; R7/R11 3.3k; R8/R12 1.6k. D1/D2 BAT42W; C1/C2 10 nF; R23 2.7k. The 2 kW C1/C2 and R23 values were directly confirmed on populated hardware by the owner. All remaining values come from the matching curated schematic.

Each T1/T2 has 16 turns of 21 AWG high-temperature enameled copper wire. Use one Fair-Rite 5943001401 #43 toroid(s) per transformer, 2 cores total per PCB. See [construction evidence and unresolved lead mapping](../transformer-construction.md).

Review all reference designators against the selected schematic; the common PCB's component value fields describe the default 200 W population and do not select the 2 kW parts. Hand assembly uses the BOM and native placement drawing together. No automated pick-and-place package has been validated.

Historical measured forward evidence contains 19 points through 250 W. The reflected 1.15 multiplier is experimental. Establish calibration for the actual completed system; see [calibration provenance](../../calibration/profile-traceability.md).
