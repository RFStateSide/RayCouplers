# Repository readiness and file-selection policy

Canonical repository: **RFStateSide/RayCouplers**, https://github.com/RFStateSide/RayCouplers. The initial engineering-reference commit was created and pushed in Phase 4. This Phase 5A status record, dated 2026-10-11, describes private preparation: public visibility, commit/push of these corrections, website coordination and releases require separate owner authorization. Read this as a dated milestone, not a permanent visibility assertion.

[Repository inventory](repository-inventory.csv) records the proposed corrected distribution selection independently from public provenance status. The original commit contains 79 files; Phase 5A adds .gitattributes and two documentation files. No automatic backups/cache files are selected. Tracked custom libraries remain selected with individual provenance classified separately.

Exclude archive/, manufacturing/historical/, calibration/measurements/, generated/, validation/, Python/editor/KiCad local state, private external-model inventory and phase file lists. Excluded evidence remains unchanged. .gitignore is a guardrail, not access control: review proposed distributed bytes before publication. The owner approves the historical PCBWay order identifier as public manufacturing provenance; this approval does not include the private order documents themselves.

Owner authorship of custom footprints and the T1/T2 symbol, plus original photography and AI-assisted editing, is documented. In response to the focused Phase 5A source question, the owner additionally confirms drawing the MC74AC74DR2G and trimmer symbol families, including related aliases. The specific symbol-origin questions are resolved by that direct evidence; retained KiCad-derived portions keep upstream notices. Final company/license/liability review and publication approval remain owner decisions. Existing physical lead-mapping, sourcing, ERC/DRC, RF qualification and 0.2 mm versus 8 mil limitations remain disclosed; they do not automatically bar AS-IS source publication.

Original workbook creator metadata remains outside the distribution. Measured CSV excerpts retain source-cell provenance. Any later workbook or archival release requires separate selection while preserving originals.

Newcomer checks use no private originals: `python tools/prepare.py --projects`, `python tools/validate.py --portable`, `python tools/manufacturing.py --check`. Set KICAD_CLI to the installed executable. validation-baseline.json is the approved geometry/netlist fingerprint, not another editable PCB. Normal owner-local validation can additionally check external preservation. See [editing workflow](editing-workflow.md) and [distribution integrity](distribution-integrity.md).
