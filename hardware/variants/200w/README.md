# 200 W source representation

The authoritative 200 W schematic and project are `../../common/RayCouplers.kicad_sch` and `../../common/RayCouplers.kicad_pro`. This avoids a duplicate editable schematic. The common project's PCB is the sole curated PCB authority.

Generate a disposable 200 W project using `python tools/prepare.py --projects` from the workspace root. Do not maintain a separate PCB here.
