# Project CAD collection and attribution

This collection was extracted from historical embedded project assets and localized during release preparation. Pin definitions and footprint geometry were retained. Some standard-library-derived items were renamed and instance metadata corrected; this is not a claim of original authorship.

Standard KiCad-derived portions: KiCad library contributors; CC-BY-SA-4.0 with KiCad-libraries-exception. See the unmodified upstream LICENSE-KiCad.md (including its official CC-BY-SA-4.0 legal-text link), KiCad-libraries-exception.txt and https://www.kicad.org/libraries/license/. KiCad distinguishes design/generated output use from redistribution of library collections; the exception does not remove the collection attribution/share-alike obligations. Keep applicable upstream notices.

Historical custom namespaces My/my/Ray have not established all original creators or vendor download terms. RF_Pad_HF, RF_Pad_HF_Sm and SWRVoltageTransformer contain project-specific geometry; SOIC127P600X175-14N and TRIM_3296W1103LF names resemble vendor/ECAD generator output but names alone do not prove provenance. The SOD-123 symbol/footprint and several custom symbols may derive from standard or vendor definitions. Owner confirmation of authorship/download source or permission is needed before declaring the entire collection publicly cleared. No external STEP model was bundled. Installed stock 3D models remain external dependencies.
